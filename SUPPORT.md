# Support

## Choose the right channel

| Need | Where to go |
| --- | --- |
| A reproducible defect in this repository | Open a GitHub Bug Report issue. Include steps, expected behavior, actual behavior, and safe logs/screenshots. |
| A small, well-defined enhancement | Open a GitHub Feature Request issue. Explain the user problem and expected outcome. |
| A broad idea, design question, or architecture discussion | Start a GitHub Discussion before filing an implementation issue. |
| A contribution question | Read [CONTRIBUTING.md](./CONTRIBUTING.md); then use GitHub Discussions if still blocked. |
| A security vulnerability or accidental exposure of data/credentials | **Do not open a public issue.** Email the repository owner privately at `shikanon@tensobytes.com`, including impact, reproduction, and a safe contact method. |

The project cannot provide support for third-party advertising platforms, model providers, customer accounts, or content-rights disputes. Contact the relevant provider or rights holder for those matters.

## Before filing

- Search existing issues and discussions.
- Remove credentials, account IDs, customer data, personal data, and copyrighted media.
- State the cookies version or commit, environment, and exact steps to reproduce.
- Keep the report focused on one problem.

## Response expectations

This project is maintained on a best-effort basis. Maintainers aim to acknowledge security reports promptly and triage public reports when capacity permits; no response-time guarantee is made for pre-release software.
