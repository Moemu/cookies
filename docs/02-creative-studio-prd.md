# 广告创意创作 PRD

| 属性 | 内容 |
| --- | --- |
| 模块 | 广告创意创作 |
| 文档版本 | v0.4 |
| 文档状态 | 草案 |
| 目标版本 | M1 / MVP |
| 核心形态 | 图文创作 + 视频创作 |
| 重点渠道 | 图文：小红书、公众号；视频：抖音、快手 |
| 视频类型 | 品牌广告、买量广告 |

## 1. 产品定义

本模块把已批准策略转化为适配具体渠道的创意内容。创意不是一个泛化的“文案 + 图片”对象，而是两条差异明显的生产线：

1. **图文创意**：面向小红书、公众号等内容渠道，交付可发布的图文内容包。
2. **视频创意**：面向抖音、快手等短视频渠道，并进一步区分品牌广告和买量广告。

不同形态共享品牌知识、素材经验、版本、评审与合规能力，但拥有不同的内容结构、生成 Skills、质量标准和效果指标。

## 2. 产品目标

1. 从策略快速生成符合小红书、公众号表达习惯的完整图文内容，而非只生成零散文案。
2. 为抖音、快手分别生成渠道适配的视频方案、脚本、分镜、素材组合和成片草稿。
3. 品牌视频以品牌记忆、叙事与调性为核心；买量视频以转化、钩子和可测试变量为核心。
4. 将品牌规则、素材经验和历史效果纳入创作上下文，减少同质化与重复踩坑。
5. 支持多方向探索、受控变体、人审、合规与效果回流。

### 非目标

- 不用同一套模板同时覆盖图文、品牌视频和买量视频。
- 不在 MVP 阶段替代专业图像精修、调色和复杂非线性剪辑工具。
- 不将模型评分或历史高表现模式当作效果承诺。
- 不自动发布内容或上线广告；交付后由发布/投放流程执行。
- 不复制未经授权的竞品内容、人物形象、音乐或字体。

| 类型 | 内容 |
| --- | --- |
| 本系统拥有 | CreativeTask、CreativeDirection、CreativeDraft、CreativeVersion、ProductionAsset、CreativePackage、CreativeReview |
| 从基座读取 | 用户组织、品牌知识、统一模型 Provider（LLM/VLM/图片/视频/音频/3D）、SkillDefinition、AgentTask、对象存储 |

### 创意任务内导航

进入一个 Creative Task 后，导航为：`概览 → 创意方向 → 内容编辑 → 制作素材 → 变体 → 检查 → 评审 → 交付 → 效果回流`。图文和视频在“内容编辑”后进入不同编辑器，但任务状态、版本和评审入口保持一致。

### 导航规则

- 图文和视频是平级主导航，不用筛选器隐藏在同一个通用编辑页面中。
- 视频创作内将品牌视频与买量视频作为固定二级入口，分别记忆工作区状态。
- Provider 配置、品牌知识和用户管理只链接到 `/admin/*`，创意系统不复制公共管理页面。
- “效果回流”只显示引用的素材洞察和投放结果，不在本系统创建分析结论。
- 导航权限使用 `creative.*` 动作，并支持文案、设计、剪辑、品牌审核等系统内角色。

## 3. 创意分类

### 3.1 分类树

| 一级形态 | 渠道 | 二级类型 | 主要目标 | 核心交付物 |
| --- | --- | --- | --- | --- |
| 图文 | 小红书 | 笔记/种草图文 | 兴趣、信任、收藏、互动、搜索承接 | 标题、正文、话题、封面、配图、发布建议 |
| 图文 | 公众号 | 文章/品牌内容 | 深度表达、品牌心智、私域承接 | 标题、摘要、头图、文章、内文配图、CTA |
| 视频 | 抖音/快手 | 品牌广告 | 认知、记忆、情绪、品牌资产 | 创意概念、脚本、分镜、声音、字幕、品牌版成片 |
| 视频 | 抖音/快手 | 买量广告 | 点击、线索、下单、安装等效果转化 | 多钩子脚本、分镜、素材组合、CTA、多变体成片 |

### 3.2 分类必填字段

每个 Creative 必须保存：

- `format`：`image_text` 或 `video`。
- `channel`：`xiaohongshu`、`wechat_official_account`、`douyin`、`kuaishou`。
- `video_purpose`：视频必填，`brand` 或 `performance_acquisition`。
- `objective`：品牌或效果目标。
- `audience_segment`：目标人群。
- `strategy_version_id` 与 `asset_insight_ids`：策略和素材经验依据。

## 4. 用户与场景

| 角色 | 场景 | 成功标准 |
| --- | --- | --- |
| 内容运营 | 为新品生成一批小红书种草笔记 | 可直接评审，标题、正文、封面和配图表达一致 |
| 品牌编辑 | 把品牌故事写成公众号文章 | 结构完整、语气统一、事实与引用有来源 |
| 品牌创意 | 为抖音/快手策划品牌视频 | 有清晰叙事、品牌记忆点和渠道适配 |
| 买量编导 | 批量生产效果视频变体 | 钩子、卖点、证明、CTA 变量清楚，可做实验 |
| 设计/剪辑 | 接手 AI 生成的内容初稿 | 素材、字幕、镜头、时长和版本关系明确 |
| 审核人 | 审查品牌、事实和合规 | 能按形态查看专属检查项，批准具体版本 |

## 5. 统一创作流程

1. 用户从已批准策略发起创意任务。
2. 选择一级形态、渠道；视频继续选择品牌广告或买量广告。
3. 系统加载对应渠道 Skill、品牌规范和素材经验。
4. Codex 生成 3—5 个有明确差异的创意方向，说明受众、洞察和适用场景。
5. 用户选择方向，生成完整图文内容包或视频创意包。
6. 系统执行形态专属的品牌、事实、渠道规格和合规检查。
7. 用户对话式修改或在编辑器中精修，锁定满意元素后生成受控变体。
8. 创意提交评审；批准版本进入素材分析并交给发布/投放模块。
9. 效果数据回流后，系统在创意详情展示表现与素材经验结论。

## 6. 图文创意要求

### 6.1 小红书图文

#### 交付内容

- 3—10 个标题候选及标题角度说明。
- 正文：开场、场景/痛点、体验/证明、产品价值、行动引导。
- 话题与关键词建议，区分品牌词、品类词、场景词。
- 封面文案、封面构图和图片生成/选材建议。
- 图组大纲：每张图的目的、画面、文案和顺序。
- 评论区互动建议、发布时间建议和风险提示。

#### 质量重点

- 表达自然、具体，不堆砌空泛营销术语。
- 种草体验、事实证明和商业信息边界清楚。
- 标题与正文承诺一致，不使用无法证明的夸张主张。
- 图组形成连续叙事，不只是同一主图的尺寸变化。

### 6.2 公众号图文

#### 交付内容

- 标题、备选标题、摘要和分享文案。
- 头图方向、文章大纲和完整正文。
- 章节标题、重点引用/数据、内文配图说明。
- 品牌信息、产品/活动 CTA、落地链接和必要声明。
- 阅读节奏与移动端排版建议。

#### 质量重点

- 逻辑完整，适合中长内容阅读。
- 品牌语气稳定，引用、数据和产品信息可追溯。
- 标题、摘要、头图和正文主张一致。
- CTA 与文章目标匹配，避免突兀硬转化。

## 7. 视频创意要求

### 7.1 共同交付结构

- 创意概念与一句话核心表达。
- 视频时长、比例、渠道、受众和目标。
- 脚本：画面、台词/口播、字幕、音效和转场。
- 分镜：镜头时长、景别、主体、动作、场景和所需素材。
- 封面、标题、发布/广告文案和 CTA。
- 素材清单：已有、需拍摄、需生成、音乐/字体/人物授权。
- 成片草稿及可编辑工程/清单（取决于接入的生成与剪辑能力）。

平台时长、文字、画幅和文件限制从版本化渠道规则读取，不在 PRD 中硬编码易变化参数。

### 7.2 品牌广告

#### 创作目标

建立品牌认知、情绪连接和记忆资产。评价重点是品牌辨识、叙事完整、情绪一致、视觉与声音资产沉淀，而非只看短期点击。

#### 推荐结构

1. 品牌或人群洞察引入。
2. 冲突/情境展开。
3. 品牌价值与产品角色自然出现。
4. 记忆点：符号、口号、声音、角色或视觉母题。
5. 品牌收束与行动提示。

#### 专属检查

- Logo、品牌色、语气、产品露出和记忆资产是否一致。
- 故事是否在目标时长内完整，不因渠道适配破坏核心表达。
- 不因追逐前三秒钩子而损害品牌形象。
- 品牌主张和社会/文化表达是否存在风险。

### 7.3 买量广告

#### 创作目标

在清晰转化目标下快速验证表达。评价重点是钩子、痛点、卖点、证据、CTA、可测试性和单位产出效率。

#### 推荐结构

1. 开场钩子：问题、结果、反差、场景或强利益点。
2. 痛点与受众识别。
3. 产品机制、核心卖点和使用演示。
4. 证明：体验、数据、口碑、前后对比或权威信息。
5. CTA、优惠/稀缺信息与必要声明。

#### 变体原则

- 默认围绕钩子、受众、卖点、证明、CTA、人物/场景分别建立变量。
- A/B 对照尽量一次只改变一个主要变量。
- 每个变体记录假设和期望影响，不只记录文件差异。
- 快速产量不能绕过事实、授权和合规检查。

## 8. 创意 Skills

| Skill | 作用 |
| --- | --- |
| `xiaohongshu-image-text` | 生成小红书标题、笔记、话题、封面和图组方案 |
| `wechat-article` | 生成公众号标题、摘要、大纲、正文、头图和 CTA |
| `brand-video` | 生成品牌视频概念、脚本、分镜和品牌记忆资产方案 |
| `performance-video` | 生成买量视频脚本、钩子、变体矩阵和 CTA |
| `douyin-adaptation` | 按抖音渠道语境和规则适配视频包 |
| `kuaishou-adaptation` | 按快手渠道语境和规则适配视频包 |
| `creative-compliance` | 检查事实、品牌、版权、行业和渠道风险 |
| `creative-variation` | 按锁定元素和变量生成可解释变体 |

渠道 Skill 与广告类型 Skill 可以组合执行。例如“快手买量视频”由 `performance-video` + `kuaishou-adaptation` 共同完成，并保存两个 Skill 的版本。

## 10. 编辑、评审与状态

### 10.1 工作台

- 左侧：形态/渠道、策略摘要、创意方向和版本树。
- 中间：图文编辑器或视频脚本/分镜时间线与预览。
- 右侧：品牌规范、素材经验、检查结果、Skill 记录和评论。
- 底部：候选与变体对比，显示本次改变的变量。

### 10.2 状态

`草稿 → 生成中 → 待检查 → 待评审 → 已批准 → 已交付 → 已停用`

- 严重检查项存在时不能提交或批准。
- 已批准版本不可修改；改动创建新版本并重新评审。
- 已交付版本停用时保留投放与分析历史。

### 10.3 评分

共同维度：策略匹配、品牌一致、事实可靠、渠道适配、合规风险。

- 小红书：标题/正文一致、真实感、图组叙事、互动潜力。
- 公众号：结构、信息深度、阅读节奏、品牌表达、CTA 衔接。
- 品牌视频：品牌辨识、叙事、情绪、记忆资产、制作完成度。
- 买量视频：钩子、卖点、证明、CTA、可测试性和信息效率。

评分用于提示问题，不作为投放效果预测。

| `POST /api/creative/v1/versions/{id}/approve` | 批准具体版本 |
| `POST /api/creative/v1/versions/{id}/deliver` | 生成发布/投放包并交接下游 |

长任务返回 Job ID，逐项保存使用的 Skill、模型、提示词/参数、成本、素材来源和错误。重试只处理失败项。

## 12. 指标与埋点

### 12.1 通用指标

- 策略批准到首批可评审创意的中位时长。
- 每种形态的方向采用率、首轮通过率、平均修改轮次和交付率。
- Skill/生成任务成功率、P95 时延和单个采用创意成本。
- 事实、品牌、版权和合规问题检出率。

### 12.2 分类指标

- 小红书：发布率、阅读/曝光、互动、收藏、搜索或转化指标（按业务数据可用性）。
- 公众号：打开、阅读完成、分享、关注或 CTA 转化。
- 品牌视频：播放完成、互动、品牌搜索/认知等可获得指标。
- 买量视频：点击、转化、CPA、CVR、ROAS、素材衰减和变体胜出率。

指标展示必须包含渠道、目标、受众、投放环境、时间和样本提示。

## 13. 非功能要求

- 文本编辑操作 P95 小于 300ms；图像、视频生成与渲染采用异步任务。
- 视频任务支持排队、取消、逐镜头重试和部分结果保留。
- 原始上传和已批准版本不被生成任务覆盖。
- 每种形态使用独立 Schema，禁止把缺失字段静默填成无意义默认值。
- 批量生成前展示候选数量、预计耗时和成本，并受组织配额限制。
- 预览与最终交付在字幕、时序、裁剪、字体和音轨上保持可验证一致。
- 上传、生成、转码、预览、Asset ID/Version、权利元数据和删除遵循 [媒体资产平台](./11-media-asset-platform.md)。
- AI 标识、页面状态、并发编辑和需求追踪遵循 [PRD 通用交互与质量要求](./15-prd-cross-cutting-requirements.md)。

## 14. MVP 验收标准

1. 创建任务时必须明确图文/视频和渠道；视频未选择品牌/买量不能继续。
2. 小红书任务能交付标题、正文、话题、封面和连续图组方案。
3. 公众号任务能交付标题、摘要、头图、大纲、完整正文、配图和 CTA。
4. 品牌视频任务能交付有品牌记忆点的脚本、分镜、声音与成片草稿。
5. 买量视频任务能生成至少 3 个钩子变体，并清楚记录唯一主要变量。
6. 抖音与快手任务调用对应渠道 Skill，输出中能查看 Skill 版本。
7. 锁定品牌 Logo、主张或指定镜头后重生成，其内容保持不变。
8. 视频部分镜头生成失败时保留成功镜头，只重试失败部分。
9. 严重事实、授权或合规问题未解决时不能批准和交付。
10. 审核批准具体不可变版本；修改后必须重新评审。
11. 交付包包含内容、素材来源、授权状态、版本、渠道规则和检查结果。
12. 投放效果回流后，能按图文、品牌视频、买量视频分别进入素材分析。
13. `/creative/*` 独立提供图文、视频、制作、评审和交付导航；素材洞察或投放系统不可用时仍能完成创意草稿工作。

## 15. 依赖与风险

| 风险 | 缓解措施 |
| --- | --- |
| 四类内容被同一模板同质化 | 形态/渠道/目标独立 Skills、独立 Schema 和评测集 |
| 图文只生成文案不形成内容包 | 强制封面、配图/图组、排版和发布信息验收 |
| 品牌视频被买量逻辑侵蚀 | 独立目标、评分和审批标准，不以短期点击单一评价 |
| 买量视频批量低质或违规 | 受控变量、证据绑定、配额、合规阻断和人审 |
| 视频生成成本和失败率高 | 分镜先确认、低清预览、逐镜头生成、缓存和失败重试 |
| 平台规则变化 | 渠道规则版本化，Skills 独立升级与回滚 |
| 历史经验造成路径依赖 | 经验显示适用条件，同时保留探索配额和新方向 |

## 16. 待确认项

1. MVP 视频成片的质量标准和接入的生成/剪辑能力。
2. 小红书、公众号是否需要直接发布；本稿默认只生成发布包。
3. 品牌广告与买量广告是否需要不同审批角色。
4. 首期渠道规则、版权音乐、字体和人物授权来源。
5. 抖音/快手各自的首批行业模板和评测样例。
