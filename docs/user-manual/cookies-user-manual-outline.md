# 五、创意创作

## 5.1 模块总览

创意创作用于承接 Project 中已经确认的需求、策略和素材，完成图文、视频、音频、剪辑、检查与交付。进入模块后，系统会自动关联当前 Project，不需要重复创建项目或重新填写已有上下文。

左侧导航分为三组：

- **工作：**创意任务，用于统一查看和继续所有创作任务。
- **创作：**图文创作、视频创作、制作中心。
- **协作与输出：**素材检查、交付中心。

> 【图片位置 5-1：创意创作模块总览】
> 建议截图范围：顶部 Project 信息、左侧完整导航和主工作区。请标注创意任务、图文创作、视频创作、制作中心、素材检查、交付中心六个入口。

使用前请确认顶部显示的是正确的 Project。创作过程中产生的任务、草稿、生成结果和素材版本都会归属于当前 Project。

## 5.2 创意任务

### 5.2.1 新建与筛选任务

创意任务页是创意创作模块的统一任务入口。它同时展示最近真实创作和批量运营任务，可从这里创建新任务、恢复未完成任务，或按状态查找历史任务。

操作步骤：

1. 在左侧导航点击“创意任务”。
2. 点击右上角“新建创意任务”创建任务，或在“最近真实创作”中打开已有任务。
3. 使用顶部状态页签筛选全部、进行中、等待输入、生成中、待评审、已完成、失败或归档任务。
4. 在批量运营区域按任务名称、ID 或素材名称搜索，也可使用“我的任务”“今日到期”“质检未通过”“待人工确认”“需要修改”“生成失败”等快捷视图。
5. 勾选一个或多个任务后，系统只显示这些任务共同支持的批量操作。

支持的批量操作包括：分配负责人和截止时间、添加渠道规格、开始或重新生成、运行大模型质检、进入人工检查、导出确认版本和归档。

### 5.2.2 任务详情与上下游来源

任务列表展示任务名称、任务 ID、关联素材、客户与 Project、渠道规格、负责人、优先级、截止时间、质检状态、人工确认状态、交付状态和当前版本。

点击任务后，右侧详情区会显示任务说明、客户与品牌、Project、关联素材及完整状态链路。点击“继续制作”可返回对应的图文、视频或剪辑工作区；来源任务和素材版本用于追溯本次创作使用的输入。

注意：从策略进入的任务会携带已经确认的策略上下文；直接创建的任务使用人工填写的创作需求。系统不会用虚构 Brief 替代未接入的策略信息。

### 5.2.3 任务状态、失败和归档

常见任务状态如下：

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 等待输入 | 必填信息或素材尚未齐全 | 打开任务补充输入 |
| 进行中 / 创作中 | 用户仍在编辑脚本、分镜或配置 | 继续制作并保存 |
| 生成中 | 模型或渲染任务正在执行 | 等待完成，可到制作中心查看进度 |
| 待评审 / 待人工确认 | 已产生结果，等待人工审核 | 进入素材检查确认或退回 |
| 已完成 | 创作结果已经完成 | 进入素材检查或交付中心 |
| 失败 | 生成或渲染任务执行失败 | 查看错误详情，修正后重试 |
| 已归档 | 任务不再参与日常运营 | 仅用于历史查询和追溯 |

归档不会删除任务和素材版本。执行重新生成前，请先确认当前 Prompt、参考素材和授权状态，避免重复消耗模型额度。

## 5.3 图文创作

### 5.3.1 直接输入创作需求

图文创作支持小红书和公众号内容，也提供草稿与图文版本入口。直接输入适用于尚未从策略任务进入，但已经明确创作目标的场景。

操作步骤：

1. 在左侧导航点击“图文创作”。
2. 选择“小红书”或“公众号”页签。
3. 填写创作目标、目标受众和核心信息，这三项为必填项。
4. 按需填写行动引导、语气风格、视觉关键词、必须出现和禁止表达。
5. 点击“创建并规划创意方向”。系统先生成 3 个创意方向，由用户确认后再创建图文任务。

“必须出现”适合填写品牌名、产品卖点或法务要求；“禁止表达”用于约束虚构功效、敏感词或不允许出现的内容。

> 【图片位置 5-5：图文创作直接输入表单】
> 建议截图范围：小红书/公众号页签、最近图文创作、输入表单和“创建并规划创意方向”按钮。

### 5.3.2 从策略任务进入

当策略任务已确认 Creative Direction 后，可从策略工作区进入图文创作。系统会自动携带目标人群、核心信息、语气、品牌规则和渠道要求。进入后仍应检查字段是否完整，再生成创意方向。

如果页面没有显示策略内容，请先确认当前 Project 是否正确，以及上游策略是否已完成确认。未接入策略时，可以改用直接输入方式创建任务。

### 5.3.3 小红书图文

小红书图文重点关注封面吸引力、标题与正文节奏、图片组顺序、品牌露出和平台表达规范。完成创意方向确认后，按照任务内步骤生成文案与图片，检查封面、图组和排版，再进入素材检查。

建议重点检查：首图是否能传达核心信息、标题是否过度承诺、图片比例是否符合渠道要求、品牌名和产品卖点是否准确、图片与正文是否一致。

> 【图片位置 5-6：小红书图文任务详情】
> 建议在创建真实图文任务后截图，标注文案区、封面/图组、版本信息和审核入口。

### 5.3.4 公众号图文

公众号图文适合较长内容和完整叙事。创建方式与小红书一致，但应重点检查标题层级、段落结构、首图、正文配图、行动引导和长图文阅读体验。

> 【图片位置 5-7：公众号图文任务详情】
> 建议在创建真实公众号任务后截图，标注标题、正文排版、配图和预览区域。

### 5.3.5 草稿与图文版本

“草稿箱”用于继续尚未完成的图文任务；“图文版本”用于查看已经生成或保存的版本。页面顶部的“最近图文创作”会展示真实任务，点击任务可继续生成、查看成品或进入审核。

系统会自动保存服务端草稿。重新生成会形成新的结果或版本，不应覆盖已经确认的版本。进入审核前，请确认打开的是正确的任务和版本。

- 已配置可用的文本、图片或视频模型；生成任务可在制作中心追踪。

### 5.4.3 AI 原生效果广告

#### （1）需求分析

AI 效果广告生成从商品链接或商品需求开始，依次完成需求分析、脚本生成、故事板生成和视频生成。新建广告后，先确认商品信息、目标平台、画幅、时长和生成要求。页面会显示当前广告记录和创作规格，便于切换历史广告继续处理。

> 【图片位置 5-11：AI 效果广告—需求分析】
> 请标注商品来源、当前广告、渠道规格、需求字段和进入脚本生成的按钮。

#### （2）脚本生成

系统生成一份完整营销脚本，并按 Hook、痛点、证据、利益点和 CTA 等片段组织。每个片段可编辑画面内容、旁白、字幕、使用卖点 ID 和转化动作。

不满意时，可填写“重新生成要求”并点击“重新生成整版”；确认无误后点击“确认并生成故事板”。重新生成会替换当前工作草稿，操作前建议保留已确认版本。

> 【图片位置 5-12：AI 效果广告—脚本生成】

#### （3）故事板生成

故事板阶段会将脚本拆成详细分镜，并为每个镜头生成或关联图片素材。逐镜头确认画面、素材和描述；单个素材失败时优先只重试失败单元，避免整套重新生成。

#### （4）视频生成

视频阶段按分镜生成视频单元，并结合旁白、字幕或音频形成最终成片。运行中可在制作中心查看每个 Provider 任务的进度和输出。部分单元失败时，检查错误详情后重试对应单元；全部完成后再合成预览并保存为 Project Asset。

### 5.4.4 电商前贴

流程为：选择原视频 → 确认内容理解 → 选择钩子方向 → 设置时长与三段节奏 → 选择参考首帧 → 生成前贴成片。

生成完成后可直接播放，查看时长、画幅、来源原视频和参考首帧。点击“再生成一版”获得新候选，确认后点击“保存到素材库”；需要制作其他内容时可点击“新建另一个前贴”。

生成失败时应查看页面错误信息。若模型提示参考图包含真人或触发内容安全限制，请更换参考图、降低人物相似性或调整 Prompt 后重试，不要连续重复提交同一输入。

### 5.4.7 爆款复刻

1. 上传爆款源视频，并按需上传产品或风格参考图片。
2. 填写文本指令、源视频 Asset ID、版本、标题和时长。
3. 点击“视觉理解拆解五维提示词”。系统会输出任务目标、画质/风格/光影、环境氛围、镜头画面和音乐/音效五个维度。
4. 填写目标产品、核心卖点和 CTA，检查自动生成的复刻视频总提示词。

### 5.4.9 素材剪辑

素材剪辑用于将已授权的视频、图片、字幕和音频组织为可交付版本。任务列表可按全部、草稿、渲染中、待评审、已完成和失败筛选。

进入剪辑任务后：

1. 在左侧素材区上传或筛选视频、图片，选择目标轨道后点击“加入所选轨道”。
2. 在时间线上管理主视频、叠加轨、字幕、配音、音乐和音效。
3. 使用播放、撤销、重做、分割、删除、吸附和缩放工具调整时间线。
4. 在右侧设置画布比例、轨道锁定/静音/隐藏和片段属性。
5. 保存后生成低清预览；确认规格、冻结版本并完成人工批准后，再执行正式导出和交付封包。

如果提示某个片段引用的素材版本不可用，应删除或替换该片段，或确认对应 AssetVersion 是否仍可访问。按钮处于禁用状态通常表示时间线为空、素材不可用，或尚未完成前置检查。

推荐流程：

2. 根据使用场景生成发布包或投放包，并确认包内素材、规格和授权清单。

4. 下载后可在“下载记录”追溯操作；失效或停止使用的版本进入“停用版本”。
