# 用户手册素材目录

本目录用于存放 Cookies 用户手册中的截图、流程图和短视频封面。

## 命名规则

```text
模块编号-功能编号-步骤编号-简短说明.扩展名
```

示例：

```text
04-03-01-策略工作区总览.png
05-04-03-AI原生广告需求分析.png
07-03-02-投放计划预算配置.png
```

## 截图要求

- 使用同一浏览器窗口尺寸和缩放比例。
- 遮盖真实客户名、账号、手机号、密钥、预算等敏感信息。
- 用红框或数字标注操作区域，但不要遮挡按钮文案。
- 一个步骤只表达一个操作重点。
- 页面发生明显改版后及时替换旧截图。
- 需要展示动态操作时，可在飞书正文中插入短视频；本目录仅保存其封面或必要附件。
