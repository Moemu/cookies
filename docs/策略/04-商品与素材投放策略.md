# 商品与素材投放策略

## 1. 核心概念

“商品 × 素材”是商品对象与具体创意内容的组合。来源资料认为，更丰富且有效的组合有利于获得投放空间；同一组合被大量复制到多个广告时，消耗可能集中在少量强广告，重复广告难以获得分发。

商品可以是应用、小程序、短剧或漫剧剧目、小说书籍等；素材包括视频、图片、图文和试玩素材，不包含广告标题。该方法适用于资料所述的竞价广告场景，不覆盖 DPA。

## 2. 投前策略

- 绑定准确的商品和资产，避免为同一商品创建多个重复或近似对象。
- 完整填写商品信息、题材、版权、落地页和转化目标，提升匹配质量。
- 上线前计算同一商品、素材、转化目标组合下的广告数量。
- 为素材生成相似度、首发、高质量、低质量、低效和重复使用等诊断标签。

## 3. 投中策略

### 降低重复建设

同一商品与素材组合下，不批量复制相同广告。优先把预算集中到已产生有效信号的广告，并清理长期无消耗对象。

### 处理素材疲劳

1. P0：补充新素材，改变核心内容而非只替换边框或文案。
2. P1：使用独立预算或素材探索工具，为新素材提供公平冷启动。
3. P2：检查同一素材跨商品、转化目标和投放载体的复用情况。
4. 可选：在授权和治理允许时，建立账户或创作者矩阵。

### 内容生产参考

- 短剧 IAP：原片高光切片，突出冲突、反转和爽点。来源建议约每 5 分钟安排 1 至 2 个剧情冲突，可作为脚本密度起点。
- 短剧 IAA：二剪解说、前贴或超短素材，前 3 秒建立明确钩子。
- 漫剧：3 至 5 分钟原生内容为基础，动态漫可测试 BGM 重混和解说。
- 小说：以解说文本为核心，并测试视频、滚动文字和动漫等不同表现形式。
- 工具类：钩子前贴、真人解说、产品演示、价格和 CTA 组成基础公式。

## 4. 投后诊断

只有同时出现效果下降或不起量，以及显著的商品素材重复时，才将问题判定为组合重复风险。

| 诊断结果 | 动作 |
| --- | --- |
| 命中重复风险 | 删除重复或高度相似素材；停止新增重复广告；清理无消耗广告；预算集中到有效广告 |
| 未命中重复风险 | 按常规波动处理，检查受众、竞价、落地页、追踪和素材疲劳 |
| 数据不足 | 保持观察，不自动执行暂停或扩量 |

## 5. 实验阈值与边界

来源给出约 60% 画面差异用于降低相似度、约 90% 差异用于争取首发，以及用 5% 至 10% 预算探索浅层转化等建议。这些数值应在 cookies 中标记为“来源建议”，作为实验默认值而不是平台保证。

任何删除、暂停、扩量和预算迁移动作必须进入 ChangeSet，展示预计影响并要求对应权限的人工审批。

## 6. 监控指标

- 商品 × 素材 × 转化目标下的广告数量。
- 重复或高度相似素材比例。
- 新素材预算覆盖率和冷启动成功率。
- 素材首 3 秒留存、完播、点击、转化和疲劳斜率。
- 无消耗广告数量、预算集中度和变更后观察结果。
