## 证据分级

- `来源事实`：可直接在学习资料中定位的数据、规则或案例描述。
- `策略推导`：基于多个来源事实形成的 cookies 执行方法。
- `待验证假设`：需要结合账户、题材、渠道或实验结果验证，不能当成平台硬规则。

所有比例、阈值和预算建议均保留来源语境。上线前应由业务负责人复核，并以真实账户数据校准。
