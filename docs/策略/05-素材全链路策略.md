# 素材全链路策略

## 1. 策略目标

把一次素材生产变成可追溯的学习循环：用洞察确定机会，用制作梯度控制成本，用包装质量门保证表达，用商品与素材组合治理投放，再把结果回流为带适用边界的经验。

## 2. 五步闭环

| 阶段 | 核心问题 | 输入 | 输出 | 决策门 |
| --- | --- | --- | --- | --- |
| 1. 机会识别 | 供给与消耗哪里不匹配 | 大盘、账户、题材、历史素材 | 机会假设与优先级 | 数据口径可比 |
| 2. 创意设计 | 最低成本如何验证 | 剧情、角色、利益点、授权 | 制作梯度与变量矩阵 | 单一变量可解释 |
| 3. 包装评审 | 无声和有声状态下是否都清楚 | 初剪版本 | 五维评分与修订清单 | 评分至少 8/10 |
| 4. 投放治理 | 是否形成有效且不重复的组合 | 商品、素材、目标、预算 | 组合矩阵与 ChangeSet | 风险动作经审批 |
| 5. 复盘沉淀 | 在什么条件下有效 | 内容特征、投放数据、变更记录 | 已确认经验或失效结论 | 样本和观察窗达标 |

## 3. 统一数据字段

每个素材版本至少保存：

- Project、商品、题材、地区、渠道和目标受众。
- 制作方法层级、核心钩子、时长、CTA 和包装评分。
- 来源资产、授权范围、模型版本、提示词版本和人工修改记录。
- 商品 × 素材 × 转化目标组合、广告数量和相似度标签。
- 3 秒留存、完播、点击、转化、消耗、疲劳和观察窗口。

## 4. 决策规则

- 大盘机会只能生成“优先测试”结论，不能直接生成扩量动作。
- 素材失败先检查首屏和表达，再检查组合重复、受众和竞价。
- 自动化建议必须展示证据、适用条件、置信度和反例。
- 同一经验跨题材、地区或渠道复用时，状态自动回退为待验证。
- 预算、暂停、删除和扩量必须通过人工审批及审计记录。

## 5. 四系统协作

- 需求与策略：保存机会假设、受众、内容路线和实验设计。
- 创意创作：实现制作梯度和五维包装检查，保留版本差异。
- 素材洞察：连接内容特征与真实效果，识别反例和失效条件。
- 智能投放：治理商品与素材组合，通过 ChangeSet 安全执行。

## 6. 首轮落地建议

选择一个漫剧 Project，制作 M1、M3、M4 各 3 条素材。统一商品、受众和主要投放设置，只改变制作方法和钩子。通过包装评分后，以小预算验证 3 秒留存、点击和转化，再决定是否进入 M5 或 M6 的规模化制作。每轮只确认一条经验，保留失败样本。
