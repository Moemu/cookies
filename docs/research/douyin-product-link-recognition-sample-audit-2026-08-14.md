## 样本结构与后续统计建议

本样本共 19 条，刻意保留了不同年代、不同短链长度、不同商品类型及同一来源下的不同 SKU：

- 较早公开样本：2022—2024 年，适合验证短链过期、目标商品下架和旧跳转结构。
- 较新公开样本：2025—2026 年，适合验证当前 `v.douyin.com` 跳转和 `goods_detail` 编码结构。
- 商品类型包括食品、日化、服装鞋包、图书、数码设备、虚拟知识服务、软件和营养补充剂。
- 两条锋味派午餐肉链接来自同一公开文章但指向不同规格，可观察相近商品分享链接是否会被错误合并。

后续运行本地识别器时，建议逐条记录以下互斥结果，而不是只记录“成功/失败”：

1. `success_complete`：识别为商品，并取得商品 ID、名称及至少一张可用图片。
2. `success_partial`：识别为商品但关键字段缺失，例如只有 ID 或名称。
3. `expired_or_removed`：短链过期、商品下架或目标页已不存在。
4. `platform_blocked`：公开请求受到登录、验证码、403、429 或其他平台风控限制。
5. `parser_incompatible`：目标仍是公开商品页，但现有解析器无法处理其跳转/编码/字段结构。
6. `network_error`：本地 DNS、TLS、超时等非平台业务原因。

应同时报告两个分母：

- **端到端样本成功率** = `success_complete / 19`，反映用户粘贴这些公开分享链接时的实际体验。
- **可解析目标成功率** = `success_complete / (19 - expired_or_removed - platform_blocked)`，用于判断解析器本身的能力。

这样可以避免把多年以前已经过期的短链，错误归因成当前解析代码缺陷。

## 本地解析器实测结果

实测日期为 2026-08-14。使用当前仓库的 `cmd/cookies-resolve-product` 构建解析器，测试公开搜索得到的抖音商城分享短链，并补入用户此前提供的 2 条真实链接。去重后共 32 条。成功标准为：解析请求完成，且返回非空商品 ID、商品名称和至少一张主图；另对主图 URL 发起实际下载探测。

| 指标 | 结果 |
|---|---:|
| 链接成功解析 | 32 / 32（100%） |
| 商品 ID 非空 | 32 / 32（100%） |
| 商品名称非空 | 32 / 32（100%） |
| 主图 URL 非空且可下载 | 32 / 32（100%） |
| 原始价格字段存在 | 32 / 32（100%） |
| 销量字段大于 0 | 29 / 32（90.6%） |

首批 19 条的解析耗时均值为 298.1 ms，中位数为 267 ms，P95/最大值为 654 ms。后续 13 条新增样本耗时为 222–354 ms。

上述 100% 是本次定向公开样本的**观测成功率**，不能等同于抖音全量链接成功率或生产 SLA。样本主要来自仍被公开网页索引的商品分享链接，存在存活样本偏差；它没有覆盖私密、已下架、已过期、验证码、频控和未来页面结构变化。

### 反例与边界测试

- 3 条普通抖音视频分享链接均未被误识别为商品，说明商品类型防误判有效；但当前错误信息暴露为 `www.iesdouyin.com` 域名不受支持，对用户不够友好。
- 一段文本若先出现普通 URL、后出现抖音商品 URL，解析器会只取第一个 HTTPS URL 并失败。这是已复现的实际缺陷。
- 32 条成功结果均属于 `partial`：公开链接可提供商品基础字段，但不提供完整、可核实的商品描述与核心卖点。

### 建议优化顺序

1. **P0：多链接候选解析。** 提取文本中的全部 URL，优先匹配受支持的商品域名，而不是固定取第一个 URL。
2. **P0：错误分类与中文提示。** 区分普通抖音视频、非商品链接、短链过期、平台风控和解析器不兼容。
3. **P1：字段语义。** 将销量未知与真实销量为 0 分开；价格继续标记为待确认，避免把原始整数误当作已确认的人民币售价。
4. **P1：持续探测。** 建立少量固定短链的定时 canary，监控跳转域名、`goods_detail` 编码层数和字段结构变化。
5. **产品边界：** 当前只保留一张规范主图，不等于抓取完整商品图集；卖点仍应作为 AI 候选并由用户确认。
