# MVP 验证清单

- [x] 项目、产物、生成任务、ChangeSet 和审计记录通过服务端 API 持久化，刷新后可恢复。
- [x] 方舟 API Key 只从服务端环境变量读取，不出现在前端代码、浏览器存储、API 响应、日志或版本库。
- [x] 文本策略生成默认映射到 `doubao-seed-2-1-pro-260628`，图片和视频任务分别映射到指定模型。
- [x] 未配置 Provider、限流或生成失败时，界面保留用户输入并展示可诊断、可恢复的状态。
- [x] 图片或视频生成任务可展示排队、运行、成功、失败和取消的真实服务端状态。
- [x] 已确认 Brief 才能发起创意任务，生成内容展示 AI 标识、模型与生成时间。
- [x] ChangeSet 在缺少必要产物或预算边界时无法进入模拟执行。
- [x] 通过审批的 ChangeSet 能完成明确标记的模拟执行、生成审计证据，并可执行回滚。
- [x] 预置路演项目可以完整演示“需求 -> 策略 -> 创意 -> 审批投放模拟 -> 审计”主路径。
- [x] README 如实说明 MVP 的启动方式、环境变量、方舟模型配置与不连接真实广告平台的边界。
- [x] 前端 TypeScript 构建、后端测试和主路径冒烟验证均通过，且无新增诊断错误。
- [x] 当前前端 mock 中的项目工作项、证据、活动、指标趋势、投放诊断与建议动作均由服务端持久化 API 提供，并按 Project 隔离。
- [x] 路演示例数据的初始化可重复执行，不覆盖用户项目或已存在的用户业务记录。
- [x] 纯视觉配置、交互文案、素材模板与静态图片引用未被误建模为业务运行数据；页面不再使用静态 mock 冒充服务端已保存数据。
- [x] 项目阶段、进度、预算、状态与负责人在所有页面从相同的服务端 Project 数据或其确定性推导结果读取。
- [x] 历史项目读取时补齐可识别的服务端 runtime 默认值；路演项目与新建项目的运行字段、报告指标和建议动作均按 Project 隔离并可在刷新后恢复。
- [x] 刷新页面和重启服务后，示例项目仍完整展示需求、策略、创意、洞察、审批投放与审计的连续主路径。
- [x] 新增数据模型与种子逻辑通过服务端测试，前端 `npm run build`、`npm run check:server` 和相关测试均通过，且无新增诊断错误。
- [x] 项目总览与项目管理页在首屏清楚显示当前阶段、一个主要下一步操作、阻塞或风险提示及可追溯的项目上下文，不再由同权重卡片分散主任务。
- [x] 视频创作页以中央预览和当前镜头为视觉焦点，镜头、提示词、生成状态与不可用操作均具有清晰层级和可访问反馈。
- [x] 投后分析页先呈现可验证的核心结论、原因与建议动作，筛选、指标定义、趋势证据和广告明细提供明确下钻路径。
- [x] 所有新增或调整的状态同时使用文字和图标/形状表达，关键控件具备可见键盘焦点与屏幕阅读器名称，并尊重 `prefers-reduced-motion`。
- [x] 在 1280px、1440px 与 1680px 桌面视口下，关键操作和核心内容不被遮挡，且无横向页面溢出。
- [x] 真实 API 数据、服务不可用提示、刷新恢复和“仅模拟投放”边界在优化后保持正确；无静态 mock 冒充已保存数据。
- [x] 前端构建、相关服务端测试、前端交互测试和浏览器主路径回归均通过，且无新增诊断错误。
- [x] 投后趋势、原因、建议动作和复盘数据均按当前 Project 从服务端运营记录读取；无数据时不展示或保存固定前端业务结论。
- [x] 前贴分镜生成通过服务端任务和持久化产物完成；未配置、失败、取消及刷新恢复不会被前端定时器伪装为成功。
- [x] 浏览器端到端回归使用隔离的真实 API 和临时持久化仓储，覆盖刷新恢复和项目隔离，不使用全量 API 路由 mock 替代集成验证。
- [x] 短剧前贴规划仅接收当前 Project 已确认 Brief 下的用户审核故事上下文，稳定生成三至五个候选；候选评分明确为机制相关性而非效果预测。
- [x] 每个短剧候选展示机制、证据、评分、口播、画面意图与非逐字衔接语；用户提供的正片首句不出现在候选或服务端 Prompt 中。
- [x] 短剧前贴必须显式选择一个有效候选才能创建任务；服务端重建 Prompt，拒绝客户端原始 Prompt 覆盖，并将无敏感信息的选择快照持久化到当前 Project Artifact。
- [x] 缺少、未确认或跨 Project Brief/规划的短剧前贴请求被拒绝且不创建任务；游戏与电商前贴现有输入、隔离和生命周期回归保持通过。
- [x] 短剧前贴工作区清楚标识 AI 候选需要人工选择，规划/生成失败保留用户输入并提供恢复路径；任务成功且产物持久化前不得加入素材箱。
- [x] 在 1280px、1440px、1680px 桌面视口下，候选辅助区不遮挡中央预览、候选选择、生成、取消或加入素材箱操作，且无横向溢出。
- [x] 短剧前贴增量通过服务端测试、服务端类型检查、前端构建、真实 API 集成或 E2E、`git diff --check`；仅任务相关文件被提交、推送，远程必需 CI 检查全部通过。
- [ ] 当前工作区纳入范围的所有变更均已提交并推送，且远程 PR 必需检查覆盖最新提交并全部通过。
