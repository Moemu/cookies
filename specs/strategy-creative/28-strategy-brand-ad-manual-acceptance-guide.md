# 娇兰 KOL Brief 策略到品牌广告全链路人工验收指南

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 适用产品 | cookies 广告增长工作台 |
| 验收范围 | 娇兰 KOL PDF Brief、策略对话、联网搜索、策略生成、品牌广告交接、品牌方向与视频制作 |
| 验收方式 | 单人本地人工验收 |
| 建议耗时 | 主链路 30～60 分钟；图片、视频生成耗时另计 |
| 当前版本 | v1.0 |
| 更新日期 | 2026-08-06 |

## 2. 验收目标

使用一个全新项目和用户提供的娇兰 KOL PDF Brief，验证下面这条业务链路可以连续完成：

```text
新建项目
→ 上传并解析 PDF Brief
→ 普通对话
→ 后台联网搜索
→ 生成并确认策略
→ 选择品牌广告任务
→ 策略包交接到品牌广告
→ 生成品牌方向
→ 生成脚本、分镜和视频
→ 刷新后恢复完整上下文
```

验收重点不是“每个页面都能打开”，而是确认同一份业务信息能沿链路传递，并且不会在不同项目、不同 Brief 或不同策略版本之间串数据。

## 3. 验收结论规则

| 结论 | 说明 |
|---|---|
| 通过 | 主链路全部通过，没有 P0/P1 问题 |
| 有条件通过 | 主链路可走通，仅存在不阻断使用的 P2 问题 |
| 不通过 | 存在 P0，或存在阻断主链路的 P1 问题 |

### 3.1 缺陷等级

| 等级 | 定义 | 示例 |
|---|---|---|
| P0 | 主链路完全不可用、数据串项目、数据丢失 | 页面白屏、无法发送消息、策略交接到错误项目 |
| P1 | 关键能力不可用，但存在绕行方式 | PDF 解析失败、联网搜索总是失败、品牌方向无法生成 |
| P2 | 体验或展示问题，不阻断主链路 | 文案不清楚、内容截断、状态提示不及时 |
| P3 | 低优先级优化建议 | 间距、颜色、非关键提示文案 |

## 4. 验收前准备

### 4.1 服务检查

1. 打开前端：`http://127.0.0.1:5173`。
2. 打开后端健康检查：`http://127.0.0.1:8080/healthz`。
3. 确认健康检查返回成功，前端不是空白页。

如果前端无法打开或健康检查失败，应先恢复本地服务，不继续做业务验收。

### 4.2 测试数据

使用下面这份真实 PDF：

`<本机测试资料目录>\【娇兰】brief(1).pdf`

验收前由测试者在文件选择器中定位该 PDF；文档不绑定具体用户目录。

文件共 28 页，是一份“双十一种草”KOL 总 Brief，不是单一产品广告 Brief。系统需要识别以下事实基线：

| 类型 | PDF 中的事实 |
|---|---|
| 品牌 | 法国娇兰 |
| 沟通主题 | 双十一种草 |
| 发布平台 | 微博、小红书、抖音 |
| 发布形式 | 图文、视频 |
| 产品一 | 第三代黄金复原蜜 |
| 产品二 | 25X 蜂皇水 |
| 产品三 | 娇兰帝皇蜂姿面霜套组/娇兰复原霜 |
| 产品四 | 娇兰金钻修颜粉底液 |
| 通用视觉方向 | 金色、暖色、明亮简洁、生活氛围感 |
| 通用人物要求 | 浅色服装、自然妆感、愉悦状态，避免浓妆、过度磨皮、虚假前后对比 |
| 通用产品要求 | 产品外观和质地清晰，避免过度调色、错误摆放、指纹和不规范使用动作 |

**PDF 内容定位**

| 页码 | 内容 |
|---|---|
| 第 2 页 | KOL Brief 模板、平台、形式、双十一种草主题和未填写字段 |
| 第 3～7 页 | 第三代黄金复原蜜卖点、实验限制和使用手法 |
| 第 8～10 页 | 25X 蜂皇水卖点和消费者测试数据 |
| 第 11～15 页 | 帝皇蜂姿面霜套组/复原霜卖点和使用手法 |
| 第 16～19 页 | 黑蜂、蜂蜜、蜂皇浆和原产地教育内容 |
| 第 20～24 页 | 金钻修颜粉底液卖点 |
| 第 25～27 页 | 场景、人物和产品拍摄注意事项 |

**需要重点识别的合规风险**

- 第 6 页实验结果包含样本量、年龄、使用时间和“实际效果因人而异”等限制，不能只抽取结论数字。
- 第 7 页出现“消炎作用”表述，第 17 页出现“治愈伤口”“战争中包扎伤口”“比传统皮肤学修护剂更好”等表达。这些内容不得直接变成公开广告承诺，必须标记为待合规复核。
- 第 10 页百分比来自 61 名中国女性连续使用一个月的满意度测试，不能被改写为面向所有消费者的确定性功效。
- PDF 中各产品的成分、功效和必提词只能用于对应产品，不得跨产品拼接。

PDF 首页模板中的以下信息没有填写，系统不得自行编造：

- KOL 身份。
- 本轮主推产品。
- 渠道支持。
- Brief 时间。
- 发布时间。
- 全局目标受众。
- 具体内容时长。

为了完成后续单一品牌广告链路，本指南在系统完成歧义识别后，由测试者明确补充：

| 用户确认项 | 本轮测试值 |
|---|---|
| 主推产品 | 娇兰第三代黄金复原蜜 |
| 目标受众 | 25～35 岁、关注抗老修护和干皮护理的人群 |
| 发布平台 | 小红书、抖音 |
| 内容形式 | 30 秒品牌种草视频 |
| 沟通目标 | 双十一期间建立产品认知并促进种草 |
| 核心主张 | 稳筑「肌」本功，愈现年轻态 |

### 4.3 测试纪律

- 必须创建全新项目，不使用历史工作区完成本次验收。
- 同一轮验收只使用一份主 Brief。
- 每个关键步骤都要刷新一次页面，验证持久化。
- 遇到问题先截图，再刷新或重试，避免丢失现场。
- 不要连续重复点击生成按钮，避免创建多个相同任务。
- 图片和视频生成会产生外部模型调用，确认前置链路通过后再执行。

## 5. 全链路验收步骤

### TC-01：创建独立测试项目

**操作**

1. 新建项目。
2. 项目名称填写：`娇兰第三代黄金复原蜜全链路验收`。
3. 进入“需求与策略 → 策略工作区”。

**预期结果**

- 能正常进入项目和策略工作区。
- 页面不出现其他项目的 Brief、策略、消息或研究资料。
- 工作区顶部显示当前测试项目。
- 刷新后仍停留在当前项目。

**失败判定**

- 出现其他项目内容：P0，项目数据隔离失败。
- 新项目无法进入：P0，项目初始化失败。

### TC-02：上传并解析 PDF Brief

**操作**

1. 在“对话”页点击“添加资料”。
2. 上传 `【娇兰】brief(1).pdf`。
3. 等待解析完成。
4. 打开右侧“来源资料”。
5. 刷新页面后再次检查来源资料。

**预期结果**

- 上传后显示解析中状态。
- 解析期间输入框仍可输入，不应锁死整个页面。
- 解析完成后显示正确文件名和可检索片段数量。
- 来源资料显示 `1 / 1 可用`。
- 不出现 `strategy-conversation-brief.md`。
- 不出现历史项目的 PDF。
- 刷新后文件和解析状态仍然存在。

**内容抽查**

解析结果至少能支持识别：

- 品牌是法国娇兰。
- 沟通主题是双十一种草。
- 发布平台包含微博、小红书和抖音。
- 发布形式包含图文和视频。
- PDF 同时包含第三代黄金复原蜜、25X 蜂皇水、复原霜和金钻粉底液。
- 第三代黄金复原蜜必须使用正确产品名，强调“一蜜多用”。
- 第三代黄金复原蜜不能被描述成“油类”产品，避免沟通“过敏”“长痘”等肌肤问题。
- 产品拍摄应使用暖色调，并避免产品过度调色、错误摆放和不规范摇晃。
- KOL、主推产品、发布时间和渠道支持为空。
- 实验数据能够连同样本和限制条件一起被识别。
- “消炎”“治愈伤口”等高风险表述能够被识别为待合规复核，而不是直接生成广告话术。

**失败判定**

- 上传成功但没有可用解析结果：P1。
- 出现旧 Brief 或其他项目资料：P0。
- 刷新后附件丢失：P0。

### TC-03：关闭联网时完成普通对话

**前置条件**

确认“联网搜索”处于关闭状态。

**测试消息**

> 请根据我上传的 Brief，总结品牌、沟通主题、候选产品、发布平台、发布形式和拍摄限制。请把 PDF 已明确的事实与仍然缺失的信息分开，暂时不要替我选择主推产品。

**预期结果**

- 点击发送后，用户消息立即进入对话。
- 不出现“请求参数无效”。
- 不出现联网认证错误。
- Strategy 助手能够生成回复。
- 回复能够覆盖 PDF 中的主要事实。
- 回复明确指出这是多产品 KOL Brief，而不是已经确定主推产品的单品 Brief。
- 回复不得把复原蜜、蜂皇水、复原霜和粉底液的卖点混为一体。
- 回复明确指出 KOL、主推产品、发布时间、渠道支持和具体时长仍然缺失。
- Brief 中没有的信息应标记为待确认，不应编造。
- 用户可以继续输入下一条消息。

**失败判定**

- 无法发送消息：P0。
- 关闭联网后仍被联网服务阻塞：P0。
- 回复完全没有使用 PDF 信息：P1。

### TC-04：开启后台联网搜索

**操作**

1. 开启“联网搜索 / 后台补充”。
2. 发送下面的测试消息。

> 请联网核验娇兰第三代黄金复原蜜的公开品牌信息和官方产品表述，只补充有可靠来源支持的内容。不要把联网信息覆盖为 Brief 原文，也不要补写 PDF 中尚未确定的 KOL、发布时间或渠道支持。

3. 消息发送后立即观察对话区和输入框。

**预期结果**

- 用户消息立即进入对话，不等待联网结果。
- 消息带有“已请求联网搜索”标识。
- 消息下方出现后台搜索状态卡片。
- 不出现“请求参数无效”。
- Strategy 助手的普通回复和后台搜索分别处理。
- 联网任务不会占满或替换整个对话输入框。
- 搜索失败时，普通对话仍然可继续。

**历史问题回归检查**

重点确认以下问题不再出现：

- 开启联网后发送消息，顶部提示“请求参数无效”。
- 必须等待搜索完成后才能发送消息。
- 联网认证超时导致整个对话不可用。

### TC-05：验证联网搜索完成状态

**操作**

1. 等待后台搜索任务完成。
2. 检查原消息下方的状态卡片。
3. 打开或查看返回来源。

**预期结果**

- 状态从“联网搜索在后台进行”变为“联网补充已返回”。
- 展示简短摘要和来源。
- 来源与用户问题有关。
- 来源优先使用娇兰官网、官方品牌账号或可信媒体，不应把非官方种草文案当作产品硬性事实。
- 联网信息不会覆盖 PDF 的硬性约束。
- 联网信息不会被标记成用户已经确认的 Brief 事实。

**失败分支**

如果联网失败：

- 页面应显示明确失败状态。
- 普通对话仍然可用。
- 用户可以重试。
- 页面不能永久停留在不可恢复的加载状态。

联网失败但对话可用，记录为 P1；联网失败同时阻断对话，记录为 P0。

### TC-06：刷新恢复与重复提交保护

**操作**

1. 在联网任务进行中刷新一次页面。
2. 联网完成后再刷新一次页面。

**预期结果**

- 历史消息仍然存在。
- PDF 来源仍然存在。
- 联网任务状态能够恢复。
- 已完成的来源仍可查看。
- 不会重复创建第二个搜索任务。
- 不会重新自动发送同一条用户消息。
- 页面不白屏。

**失败判定**

- 刷新后消息或附件丢失：P0。
- 刷新后重复提交外部任务：P1。

### TC-07：深度研究与普通对话隔离

**操作**

1. 进入独立“研究”页。
2. 检查深度研究入口。
3. 返回“对话”页。

**预期结果**

- 深度研究具有独立入口。
- 普通对话输入框中没有复杂研究配置表单。
- 切换页面不会丢失对话内容。
- 深度研究失败不会使普通对话失效。
- 普通对话的后台联网搜索与深度研究任务能够区分。

### TC-08：生成可执行策略

**测试消息一**

> 本轮确认主推“娇兰第三代黄金复原蜜”，目标受众为 25～35 岁、关注抗老修护和干皮护理的人群，发布平台为小红书和抖音，内容形式为 30 秒品牌种草视频，目标是双十一期间建立产品认知并促进种草。其余未确认信息继续保留为待确认。

**测试消息二**

> 综合 Brief 和可信的联网补充，为娇兰第三代黄金复原蜜生成一份可执行策略。核心主张使用“稳筑「肌」本功，愈现年轻态”，保留“一蜜多用”、黑蜂蜂蜜、3 倍加强细胞联结、弹润亮等内容。不得称为油类产品，不沟通过敏或长痘，不使用虚假 before/after；涉及实验数据时必须保留样本和“实际效果因人而异”的限制。

**操作**

1. 检查 AI 当前理解。
2. 进入“Brief”页检查结构化结果。
3. 确认或修正关键字段。
4. 进入“策略”页生成策略。

**预期结果**

- 策略与娇兰 KOL Brief 及用户补充确认对齐。
- 不出现其他品牌或其他项目内容。
- 本轮策略只围绕第三代黄金复原蜜，不混入蜂皇水、复原霜或粉底液卖点。
- “一蜜多用”、正确产品名和必提关键词进入创作要求。
- “不称为油类产品”“不沟通过敏/长痘”“不做虚假前后对比”等进入禁止项。
- “消炎”“治愈伤口”“优于传统修护剂”等高风险说法进入合规复核项，不直接进入对外文案。
- 实验结论保留样本量、使用时间、测试方式和“实际效果因人而异”等证据边界。
- 金色、暖色、明亮简洁、生活氛围感进入视觉约束。
- 能区分 Brief 事实、联网信息、AI 推断和待确认信息。
- 策略内容能解释其对品牌广告创作的影响。
- 页面不要求用户填写与当前业务无关的全部字段。

### TC-09：选择品牌广告任务

**操作**

1. 进入“创意任务策略”。
2. 查看系统推荐和可选业务。
3. 选择“品牌广告”。

**预期结果**

- 品牌广告是可选择业务。
- 页面能够说明推荐原因或选择条件。
- 不使用来源不明的固定判断，例如没有证据的“用户为什么相信”。
- 缺少决定性条件时，页面明确显示需要补充的内容。
- 点击进入品牌广告后路由不白屏。

**失败判定**

- 品牌广告不可选择或点击无反应：P0。
- 进入品牌广告后白屏：P0。

### TC-10：验证策略包交接

进入品牌广告页面后，先不要生成，检查收到的策略输入。

**必须交接的内容**

- 项目 ID。
- Brief 或 Brief 引用。
- 策略包 ID 和版本。
- 品牌名称。
- 传播目标。
- 核心受众。
- 核心主张。
- 支撑信息。
- 禁止项。
- 投放渠道。
- 视频时长。
- 创意调性。
- 来源追溯信息。

**预期结果**

- 品牌广告页面显示法国娇兰和娇兰第三代黄金复原蜜。
- 策略主张与用户确认内容一致。
- 禁止项没有丢失。
- 页面不混入 25X 蜂皇水、复原霜和金钻粉底液的专属卖点。
- 能识别内容来自哪个 Brief 和哪个策略版本。
- 刷新后仍能恢复交接状态。
- 不需要用户复制粘贴整个策略。

**失败判定**

- 策略页面正常，但品牌广告拿不到策略：P0，Handoff 断链。
- 只传标题、丢失关键约束：P1。
- 接收到其他项目策略：P0，数据隔离失败。

### TC-11：生成三个品牌方向

**操作**

1. 点击“生成品牌方向”。
2. 观察任务状态。
3. 生成期间刷新页面一次。
4. 检查最终方向结果。

**预期结果**

- 点击后进入明确的生成状态。
- 刷新后任务不丢失、不重复创建。
- 最终生成三个真正不同的品牌方向。
- 每个方向至少包含：
  - 方向名称。
  - 核心洞察。
  - 叙事概念。
  - 品牌主张。
  - 视觉调性。
  - 渠道适配。
  - CTA。
  - 风险和限制。
- 三个方向不能只是更换标题。
- 所有方向使用正确产品名，并围绕黑蜂修护、“一蜜多用”或弹润亮等真实卖点展开。
- 所有方向避免油类称呼、过敏/长痘话题、虚假 before/after 和无来源的绝对功效承诺。
- 所有方向符合金色暖调、自然妆感、明亮生活场景等拍摄要求。

**质量校验失败处理**

如果出现 `DIRECTION_QUALITY_VALIDATION_FAILED`：

- 页面明确说明生成结果未通过质量校验。
- 页面提供“重新生成”。
- 不把失败结果伪装成可用方向。
- 重新生成后任务能够恢复。

偶发一次可记录为 P1 并重试；连续三次稳定复现，应作为阻断问题处理。

### TC-12：进入脚本与分镜制作

**操作**

1. 选择一个品牌方向。
2. 进入 Brief 确认。
3. 生成脚本。
4. 生成分镜。

**预期结果**

- 后续制作继承用户选择的方向。
- 不重新创建一个空白品牌广告任务。
- 脚本体现核心主张和禁止项。
- 产品口播使用“娇兰第三代黄金复原蜜”或“娇兰第三代复原蜜”。
- 使用手法符合 Brief：上下倾倒 1～2 次，不大力摇晃；取 2～3 滴，不展示滴管直接上脸。
- 如果脚本使用“3 倍加强细胞联结”等实验结论，应带有来源约束，不能扩写成无条件绝对承诺。
- 分镜内容与脚本段落对应。
- 页面能够追溯策略、方向、脚本和分镜之间的关系。

### TC-13：图片与视频生成

仅在 TC-01 至 TC-12 通过后执行，避免无效消耗模型额度。

**预期 provider 路由**

```text
普通/成人生图：灵裁 → Adapter → AIGAI → gpt-image-2
儿童合规生图：灵裁 → 火山 Ark 原生协议 → Seedream 5.0 Pro
普通生视频：灵裁 → Adapter → GlobalRouter → Seedance 2.0
视频理解：灵裁 → Adapter → Seed-2 Pro
图片超分：灵裁 → Adapter → 火山 MediaKit enhance-image
视频超分：灵裁 → Adapter → 火山 MediaKit enhance-video
```

**操作**

1. 生成品牌广告关键帧或分镜图。
2. 检查生成结果与所选方向是否一致。
3. 提交视频生成。
4. 观察任务状态并刷新页面。
5. 视频完成后查看和播放结果。

**预期结果**

- provider 由数据库配置层选择，不在前端写死密钥或厂商参数。
- 任务状态能够从提交、处理中进入成功或明确失败。
- 刷新后任务状态和结果不丢失。
- 外部模型失败时展示具体错误，并允许重试。
- 视频结果关联正确的策略、方向、脚本和分镜。

## 10. 最终退出标准

只有同时满足以下条件，才可以结束本轮验收：

- 深度研究和普通对话相互隔离。
- 策略内容来自当前 Brief，并保留关键约束。
- 品牌广告任务可以选择并正常进入。
- 策略包完整交接到品牌广告。
- 品牌方向可以生成，或给出明确且可恢复的错误。
- 刷新不白屏、不丢任务、不重复提交。
- 脚本、分镜和视频继承同一条策略链路。
